# Compile a concrete prompt

Resolve every bracketed field. Use this as a construction template, not a fixed theme. Never call an image tool when the current request is skill creation, analysis-only or prompt-only.

“Create one [ratio] archival cyanotype collage on near-white matte paper. [Source-role mapping: image A supplies the subject; image B supplies layout only; etc.] Extract [specific subject and anchors]. Preserve [signature silhouette cues]. Remove [specific irrelevant details]. Reinterpret subjects as contact-print impressions rather than tinted photographs.

Use [layout name], with [explicit normalized panel placements] and [module count] visual modules. Panel 01: [content and crop]. Panel 02: [different content]. Panel 03: [different content]. [Additional panels only as planned.] Maintain shared alignments, upright rectangular patches, consistent broad gutters, and about [target] percent genuinely unprinted surrounding paper. Keep one main visual anchor; leave unused space empty.

Within the image patches, use continuous deep Prussian-blue exposure fields and paper-white to pale-blue subject impressions. Restrict inner description to [essential cues]. Retain a matte absorbed-pigment feel, faint paper fiber and restrained contact-edge softness. [Optional single subordinate positive study.] Keep the global page near-white; the instruction to turn non-subject areas blue applies inside image patches.

Set only this exact copy: title [quoted title]; introduction [quoted introduction]; panel captions [quoted numbered captions]. Place text [specific placement]. Use small, readable vintage mechanical typewriter lettering, [Latin monospaced slab serif / Chinese monospaced Ming-like print], subtle ribbon ink variation, left alignment and quiet line spacing. Keep text on clean paper. Preserve the requested language and spelling.

Exclude porcelain or chinoiserie styling, ornate blue floral decoration, ceramic gloss or crackle, blue photo filters, detailed realistic shading, neon glow, vector logos, dense newspaper filler, random rotations, decorative tape, heavy shadows, extra text, fabricated specimen data, and unrelated plants or shells copied from style references.”

## Final prompt check

Verify that all source references exist and their roles are correct; every panel has source-derived content or an explicit theme-derived role; exact copy is supplied; ratios, counts and placements agree; the page remains predominantly quiet; and the instruction never implies a global blue flood. Delete unused optional template clauses. Do not append the old skill's fixed nine-square grid, mandatory color question, strong halation or two-line-footer-only rule.
