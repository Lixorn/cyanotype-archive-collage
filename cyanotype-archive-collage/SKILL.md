# Cyanotype Archive Collage

Create a quiet paper archive of extracted visual elements. First select what matters, then simplify it into cyanotype impressions, then compose the impressions and short descriptions on an ordered page. Keep this skill self-contained; do not require the original duotone skill or the original conversation.

## Route the task

- For a request to create, revise or explain this Skill, work on instructions only. Never generate a sample image unless the user explicitly asks for one.
- For prompt-only or analysis-only requests, return only the requested plan, copy or prompt. Do not invoke image generation.
- For an actual image request, use the available image-generation/editing tool and obey its current input contract. Do not substitute programmatic filters for visual reinterpretation.
- Accept a source image, several related sources, a text theme, or a source plus an added subject. In theme-only mode invent appropriate motifs without claiming they came from a photograph.
- Separate image roles: semantic source, added-subject source, style reference, layout reference. A style reference never supplies plants, fish, shells or text to an unrelated subject by default.
- If an essential source is unreadable, ask for that source again; never claim to have inspected it. For missing optional style references, use the written system below.
- Combine related sources into one collage. For unrelated images with no combination request, make separate designs; resolve an ambiguous batch briefly if necessary.
- Use the user's ratio, wording, language and requested layout. Default to 3:4 portrait, off-white paper, Prussian blue and an ordered archival layout. No color question is needed.

## Extract and abstract

Inspect all usable semantic sources before planning. Identify one main subject and two to five meaningful supporting elements or details; use fewer for simple sources. Record internally for each: source, recognizable contour, one essential cue, discarded detail, and panel role. Preserve identity through silhouette, posture, proportion and a few negative-space cuts. Keep one strongest recognition anchor in the whole composition.

Remove original backgrounds, environmental clutter, lighting, shading, surface decoration and incidental text. Inside each cyanotype patch, make everything outside the selected subject a continuous blue exposure field. Render the subject primarily paper-white or pale blue, like a contact-print trace. Do not simply tint or invert the entire source photograph. A portrait may retain a profile and hair mass; a bicycle its wheel circles and frame openings; a cat its ears, back curve and tail; a building its mass and one characteristic opening. Never convert every theme into botanical decoration.

Use one readable full silhouette plus distinct detail studies, cropped structures or repeated source-derived rhythms. Do not repeat the same whole image in every panel. Avoid reducing all elements to generic icons. Limit each panel to one principal visual idea and one or two essential internal cues; delicate stems or structural openings may remain where they carry recognition.

## Keep the cyanotype system

Use near-white paper, default #F8F7F2, and a deep Prussian-blue family, default #153E63. Permit pale exposure tones from the same family. Treat these as design anchors rather than promises of exact raster color.

Make most image area read as pale silhouettes on blue photographic paper. Allow at most one secondary blue-on-paper positive study in a default three-to-five-module composition. Never let positive blue motifs on white become the dominant language. Keep matte absorbed pigment, faint paper fiber, restrained exposure mottling and a narrow soft contact edge. Maintain readable core shapes. Avoid glossy surfaces, dramatic glow, neon cyan, watercolor brush illustration, photographic volume, ornate blue floral linework, porcelain glaze, ceramic crackle, chinoiserie borders and repeating decorative tile patterns.

Distinguish local blue background from global page background: blue fills the individual image patches, while the surrounding page remains substantially blank. Default to approximately 45–60% genuinely unprinted paper, including margins and gutters; do not count white subject silhouettes inside blue panels as page whitespace. Never fill the whole page blue merely because the user says “其他都改蓝”. If explicitly asked for a blue full-bleed variant, honor it and acknowledge the changed page treatment.

## Compose with order

Read `references/layouts-and-copy.md` to choose one layout and resolve dimensions. Plan three to five visual modules by default, fewer if the source lacks enough meaningful elements. Use straight edges, shared vertical alignments, consistent gutters and quiet rectangular paper fields. Establish one hero module and smaller supporting studies rather than equal visual weight everywhere.

Keep every card upright by default. Use no random rotations, scrapbook piles, torn-paper clutter, tape, pins, heavy shadows or dense newspaper filler. Small pigment-edge irregularities must not disturb the underlying rectangular alignment. Treat collage as an arrangement of distinct image and text pieces, not as a requirement for overlap.

## Write the labels

Use a short title, a brief introduction and two to four short element captions. Write from visible content or user-supplied facts only. Do not invent dates, species, locations, historical provenance or technical claims. Numbering such as 01–04 is editorial indexing, not a fabricated accession record.

Use vintage mechanical typewriter typography: monospaced slab-serif Latin forms, modest size, even spacing, slightly uneven ink density with crisp legibility. Prefer Courier Prime or a similar typewriter face when actually available; do not claim a specific font was used by an image model. For Chinese, retain the requested language and use restrained monospaced Ming/Song-like printed glyphs with subtle ribbon texture, not calligraphy. Do not replace Chinese with English for convenience. Use regular or medium weight, left alignment and ragged-right lines. Do not force justification with huge spaces. Keep copy on clean paper and much quieter than the images; never use large headline typography or decorative pseudo-text.

Preserve supplied copy exactly. If it exceeds the comfortable copy budget, expand the text area or propose a shorter version rather than silently deleting text or making it microscopic.

## Execute and inspect

1. Resolve task mode and reference roles; extract semantic anchors.
2. Choose layout, aspect ratio, module count and distinct module contents.
3. Lock exact title, introduction and captions before generating.
4. Read `references/prompt-template.md` and compile a concrete prompt with all placeholders resolved. Include image roles and explicitly state which reference contributes subjects versus style.
5. In generation mode, supply accessible semantic source images using the tool's supported reference mechanism. If all required references have local paths, use those; otherwise follow the tool's conversation-image mechanism without combining incompatible mechanisms. Inspect local images before editing. Do not depend on an attachment path from this skill's creation session.
6. Inspect the actual returned image if available. Check source recognition, pale-on-blue exposure logic, non-photographic abstraction, correct panel count, consistent alignment, wide blank paper, restrained material texture, and legible exact copy. Repair a substantive failure once with a focused correction if tools and the user's request allow. Never claim pixel-perfect geometry, typography or text verification without evidence.
7. Return the finished image and a brief note only. For prompt-only output, provide the module plan, exact copy and compiled prompt without claiming an image exists. If generation is unavailable, clearly provide a prompt fallback.

Prioritize source recognition and cyanotype identity, then whitespace and alignment, then copy and fine texture. If cluttered, remove a secondary module or shorten newly authored copy before shrinking gutters. If porcelain-like, restore blue exposure fields and pale contact impressions; if photographic, discard more interior detail; if generic, restore one source-specific silhouette cue.
